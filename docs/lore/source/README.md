# Archived narrative source catalogs

These catalogs are archived narrative source material. The game does not load them at runtime; they are kept for future narration work under VC-050.

Their contents reflect an earlier setting and contradict current canon: the catalogs describe a late 19th-century gothic citadel and ancient Aether, while the cataclysm occurred in 2028 and the present is 2034. Treat the current lore canon as authoritative.
