# Controls Guide & Fencing Kinetics

*Vibrant Castle* emphasizes absolute movement precision, zero-latency animation frame recovery, and readable kinetic combat control.

---

## 1. Player 1 Controls (Valen — Chrono Duelist)

Default keyboard mapping for solo adventure or Player 1 in co-op mode:

| Action | Primary Key | Alternative Key | Kinetic Description |
| :--- | :--- | :--- | :--- |
| **Move Left / Right** | <kbd>A</kbd> / <kbd>D</kbd> | <kbd>←</kbd> / <kbd>→</kbd> | Balanced athletic stride with natural cloth settling on turns. |
| **Jump** | <kbd>Space</kbd> | <kbd>W</kbd> or <kbd>↑</kbd> | Elastic vertical spring. Hold key to achieve full jump apex. |
| **Slide** | <kbd>S</kbd> + <kbd>Space</kbd> | <kbd>↓</kbd> + <kbd>Space</kbd> | Low center-of-gravity slide under spinning blades and thorns. |
| **Chrono Dash** | <kbd>Shift</kbd> | Right <kbd>Shift</kbd> | Instantaneous phase evasion with dedicated invulnerability frames. |
| **Rapier Strike** | <kbd>J</kbd> | Left Mouse Button (<kbd>LMB</kbd>) | Lightning-fast Bastion steel thrust or crisp horizontal cut. |
| **Solar Glyph Spell** | <kbd>K</kbd> | Right Mouse Button (<kbd>RMB</kbd>) | Arcane solar beam consuming mana points. |
| **Use Potion** | <kbd>Q</kbd> | <kbd>Num 1</kbd> | Instantaneous vitality restoration from backpack slots. |

## 3. Global System Hotkeys

Universal hotkeys available at any moment during play:

- <kbd>P</kbd> or <kbd>Escape</kbd>: Toggle simulation pause and resume game.
- <kbd>M</kbd>: Main Game Menu (level selection, audio, and display settings).
- <kbd>H</kbd>: Help and integrated controls reference card.
- <kbd>I</kbd>: Inventory backpack grid.
- <kbd>K</kbd>: Skill Tree and celestial constellations.
