# Controls Guide

These are the default bindings, taken from the game's shipped controls data. Every binding can be changed in the in-game menu (Controls). Keyboard and gamepad work at the same time.

---

## 1. Player 1 (Valen) — Keyboard

| Action | Keys | Notes |
| :--- | :--- | :--- |
| **Move** | <kbd>A</kbd> / <kbd>D</kbd> | Left and right. |
| **Look up / down** | <kbd>W</kbd> / <kbd>S</kbd> | Aim direction and menu-like inputs. |
| **Jump** | <kbd>Space</kbd> | Hold for a higher jump. |
| **Melee strike** | <kbd>J</kbd> | Rapier thrust or cut. |
| **Slide / dash** | <kbd>L</kbd> | Costs stamina. Forward gives a slide, the opposite direction a backstep. |
| **Spell 1 / Spell 2** | <kbd>U</kbd> / <kbd>O</kbd> | Magic abilities. |
| **Potions 1 / 2 / 3** | <kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd> | Quick-use slots. |

## 2. Player 2 (Aurelia) — Keyboard

| Action | Keys |
| :--- | :--- |
| **Move** | <kbd>←</kbd> / <kbd>→</kbd> |
| **Look up / down** | <kbd>↑</kbd> / <kbd>↓</kbd> |
| **Jump** | <kbd>Num 0</kbd> or <kbd>/</kbd> |
| **Melee strike** | <kbd>N</kbd>, <kbd>Num 1</kbd> or <kbd>,</kbd> |
| **Slide / dash** | <kbd>M</kbd>, <kbd>Num 2</kbd> or <kbd>.</kbd> |
| **Spell 1 / Spell 2** | <kbd>[</kbd> or <kbd>Num 4</kbd> / <kbd>]</kbd> or <kbd>Num 5</kbd> |
| **Potions 1 / 2 / 3** | <kbd>8</kbd> / <kbd>9</kbd> / <kbd>0</kbd> or <kbd>Num 7</kbd> / <kbd>Num 8</kbd> / <kbd>Num 9</kbd> |

## 3. Gamepad

Player 1 uses the first connected pad, player 2 the second. Both players share the same default layout (standard gamepad button numbers in brackets).

| Action | Button |
| :--- | :--- |
| **Move** | Left stick or D-pad |
| **Jump** | <kbd>A</kbd> (0) |
| **Melee strike** | <kbd>X</kbd> (2) |
| **Slide / dash** | <kbd>B</kbd> (1) |
| **Spell 1** | <kbd>Y</kbd> (3) |
| **Spell 2** | <kbd>RB</kbd> (5) |
| **Potions 1 / 2 / 3** | <kbd>LB</kbd> (4) / <kbd>LT</kbd> (6) / <kbd>RT</kbd> (7) |

The stick dead zone is 0.25. The design goal is a restricted pad layout: 2 triggers, 4 face buttons, and the bumpers as selectors for actions.

---

## 4. System Hotkeys

- <kbd>P</kbd>: pause and resume.
- <kbd>Escape</kbd>: closes the open window, or opens the menu when none is open.
- <kbd>M</kbd>: main menu (levels, audio, display).
- <kbd>H</kbd>, <kbd>?</kbd> or <kbd>F1</kbd>: help and controls card.
- <kbd>I</kbd>: inventory.
- <kbd>K</kbd>: skill tree.
- <kbd>C</kbd>: developer tools (the second menu level, for creators).

---

## 5. Using the Game on the Web Page

- Click the game (or press **Enter the Citadel**) so it receives keyboard focus.
- The game does not trap the keyboard: press <kbd>Tab</kbd> (or <kbd>Shift</kbd>+<kbd>Tab</kbd>) to leave it and return to the page. A "Skip the game" link below the viewport jumps straight to this guide.
- <kbd>F11</kbd> or the fullscreen button enlarges the game; <kbd>Esc</kbd> leaves fullscreen.
