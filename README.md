# Vibrant Castle

*Vibrant Castle* is a 2D action-adventure platformer set in a rich, melancholic gothic fantasy world bathed in an eternal golden autumn. Inspired by classic titles like *Castlevania: Aria of Sorrow*, *Owlboy*, and the dynamic responsive narration of *Bastion* and *Hades*, the game blends kinetic combat, platforming agility, and rich atmospheric storytelling.

## Overview

Players explore the ancient Citadel of Aether—once the seat of horologists, astronomers, and fencing scholars—now suspended in temporal stasis following a catastrophic fracture. As the Awakened Duelists, players navigate interconnected sectors, reactivate dormant clockwork machinery, and overcome corrupted guardians under the guidance of an omniscient Narrator.

## Key Features

* **Kinetic Combat & Fluid Locomotion**: Precise rapier thrusts, wide arcane slashes, high-speed slides, and directional dashes (`Chrono Dash` & `Phase Dash`).
* **Playable Champions**:
  * **Valen (Chrono Duelist)**: A calculated scholar utilizing rapier precision and solar glyph magic.
  * **Aurelia (Aetherblade Warden)**: An agile protector commanding organic celestial energy and an ethereal manifested blade.
* **Co-op & Solo Modes**: Experience the campaign solo or in two-player cooperative play.
* **Citadel Sectors**: A multi-tiered campaign across distinct environments including the Courtyard of Awakening, the Chasm of Thorns, the Clockwork Tower, and the Aether Sky Sanctuary.
* **Rich World & Lore**: Comprehensive documentation of characters, locations, artifacts, enemies, and lore.

## Tech Stack & Getting Started

Built with React 19, TypeScript, Tailwind CSS, Motion, and Vite.

### Prerequisites

* Node.js (v18+) or Bun / npm

### Installation

```bash
bun install
```

### Running Locally

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
