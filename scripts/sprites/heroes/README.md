Hero scripts go here, one file per character (`valen.ts`, `aurelia.ts`), each exporting `defineHeroSprite({...})`.

Valen and Aurelia are built from their painted frames by the quantizer (`source: { kind: "painted", ... }`); see "Heroes from painted frames" in `../README.md`. A hand-drawn hero starts from `../__fixtures__/sample_hero.ts`.
